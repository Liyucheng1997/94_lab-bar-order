# 🍸 酒吧点单系统 v1.2

顾客扫码自助点单，商家后台**实时**接单（SSE 推送，无需刷新）、响铃提醒、打印小票。

## 功能

### 顾客点单页 `/`
- 深色微醺风格的移动端菜单：分类吸顶导航、「今夜推荐」、酒杯插画、招牌 / 新品 / 人气 / 无酒精标签、酒精度
- 商品规格：冰量、甜度、容量（支持加价），备注快捷标签（少冰、分开上…）
- 扫码自动锁定桌号；未扫码时可从桌台列表选择或手动输入
- 下单后进入**订单追踪页**：已下单 → 制作中 → 已出品，状态由后台实时推送
- 「我的订单」查看本机今晚的全部订单
- **呼叫服务**：呼叫服务员 / 买单结账 / 冰水纸巾
- 购物车本地保存，刷新不丢；售罄商品实时变灰

### 商家后台 `/admin.html`
- **PIN 登录**（默认 `8888`，登录后在「店铺设置」修改）
- **实时订单看板**：新订单 → 制作中 → 已出品，一键接单 / 出品 / 取消 / 打印；等待超时标黄、标红
- **新订单提醒**：提示音 + 右上角弹窗（可直接接单）+ 标签页标题闪烁 + 系统通知（可选）+ 未接单每 30 秒催单提醒
- **服务呼叫**：顾客呼叫时响铃并置顶显示，处理后清除
- **自动打印**：接到新单自动弹出 80mm 小票打印（多单排队）
- **历史订单**：按日期 / 状态 / 关键字筛选，导出 CSV（Excel 可直接打开）
- **菜单管理**：增删改商品与分类、排序、一键售罄，插画 / 颜色 / 标签 / 规格可视化编辑，修改即时同步到顾客手机
- **桌台二维码**：单个 / 批量添加桌台，桌卡预览、下载、一键打印全部
- **营业统计**：今日营业额 / 订单 / 客单价（对比昨日）、平均出品用时、近 7 天、今日分时段、热销榜、品类构成
- **店铺设置**：店名、标语、顾客公告

> 价格、规格、售罄均在服务端校验，前端无法篡改。数据存本地 JSON，无需数据库。

## 运行

```bash
npm install
npm start
```

- 顾客点单： http://localhost:3000/
- 商家后台： http://localhost:3000/admin.html （默认 PIN `8888`）

若 3000 端口被其他程序占用，会自动改用 3001、3002…，启动日志会打印实际地址和局域网地址。

可选环境变量：`PORT`（端口）、`ADMIN_PIN`（首次启动时的初始 PIN）、`DATA_DIR`（数据目录）。

### 门店部署建议

1. 吧台电脑运行本服务，并**用局域网 IP 打开后台**：`http://<电脑IP>:3000/admin.html`
   （二维码会编码当前访问地址，用 localhost 生成的二维码手机打不开）
2. 进入「桌台二维码」批量添加桌台，打印桌卡摆上桌
3. 后台页面保持常开；首次打开如顶部提示「点此启用提示音」，点一下即可（浏览器要求）
4. 在「店铺设置」里修改 PIN、开启系统通知、测试提示音音量

## 自定义菜单

推荐直接在后台「菜单管理」中编辑。也可手动编辑 [`data/menu.json`](data/menu.json)：

| 字段 | 说明 |
| --- | --- |
| `name` / `en` | 中文名 / 英文名 |
| `price` | 价格 |
| `glass` | 插画：`highball` `rocks` `coupe` `martini` `pint` `bottle` `bowl` `plate` |
| `tint` | 插画主色，如 `#c2412b` |
| `tags` | `signature` 招牌、`new` 新品、`hot` 人气、`na` 无酒精 |
| `abv` | 酒精度，如 `24%` |
| `image` | 可选，商品图片地址（填写后替代插画） |
| `options` | 规格，可写在分类上作为默认：`[{ "name": "冰量", "choices": [{ "label": "正常冰" }, { "label": "1L", "delta": 40 }] }]` |
| `soldOut` | 售罄 |

## 目录结构

```
server.js             后端（Express + SSE 实时推送 + JSON 文件存储）
data/menu.json        菜单
data/orders.json      订单（运行时生成）
data/tables.json      桌台（运行时生成）
data/settings.json    店铺设置与 PIN（运行时生成）
public/index.html     顾客点单页   customer.css / customer.js
public/admin.html     商家后台     admin.css / admin.js
public/icons.js       共用的酒杯插画与图标
```
