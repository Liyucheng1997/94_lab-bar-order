# 🍸 酒吧点单系统 v1.1

顾客扫码自助点单，商家后台实时接单并自动生成可打印小票（含座位号）。

## 功能

- **顾客点单页** (`/`)：填座位号 → 浏览菜单 → 加购物车 → 备注 → 提交订单
- **商家后台** (`/admin.html`)，三个视图：
  - **订单管理**：每 3 秒自动刷新，新订单**提示音** + 可选**自动打印**；一键打印小票（座位号、订单号、品项、合计、备注）；状态管理（待处理 / 完成 / 重开 / 删除）
  - **桌台二维码**：为每张桌子生成专属二维码，顾客扫码自动带入桌号（无需手填）；支持单张下载、一键打印全部桌卡
  - **营业额统计**：今日营业额 / 订单数 / 客单价、累计数据、近 7 天柱状图、热销榜
- 价格在服务端校验，前端无法篡改
- 数据存本地 JSON 文件，无需数据库

## 运行

```bash
npm install
npm start
```

然后打开：

- 顾客点单： http://localhost:3000/
- 商家后台： http://localhost:3000/admin.html

> 同一局域网内，手机访问 `http://<电脑IP>:3000/` 即可点单。

### 桌台二维码用法

1. **用门店电脑的局域网 IP 访问后台**：`http://<电脑IP>:3000/admin.html`
   （二维码会编码你当前访问的地址，所以不要用 localhost 生成，否则手机扫不开）
2. 进入「桌台二维码」，添加桌号（A3、吧台2…）
3. 点「打印全部二维码」打印桌卡，或单张下载
4. 顾客扫码 → 自动进入点单页且桌号已锁定，直接点单即可

## 自定义菜单

编辑 [`data/menu.json`](data/menu.json)，按分类增删酒水/小食，改完重启服务即可。

## 打印说明

点「打印」后会弹出浏览器打印窗口。小票宽度按 80mm 热敏纸排版，
普通打印机也可打印。开启「新订单自动打印」后，接到新单会自动调起打印。

## 目录结构

```
server.js          后端 (Express + JSON 文件存储)
data/menu.json     菜单数据（可编辑）
data/orders.json   订单数据（运行时自动生成）
data/tables.json   桌台数据（运行时自动生成）
public/index.html  顾客点单页
public/admin.html  商家后台
public/*.js / .css 前端逻辑与样式
```
